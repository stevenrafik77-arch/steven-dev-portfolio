---

## 🛠️ Tech Stack

- **Core:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Utility-first framework)
- **Icons:** [Lucide Icons](https://lucide.dev/)
- **Typography:** Google Fonts (Inter)
- **Animations:** Custom Intersection Observer API, CSS Transitions, and Keyframes

---

## 🚀 Features

- **Dynamic Typewriter Effect:** Custom JS implementation for an engaging hero section.
- **Scroll Progress Indicator:** Real-time visual feedback of reading progress.
- **Reveal Animations:** Professional entry animations using the Intersection Observer API.
- **Bento Grid Projects:** Modern layout for showcasing work with interactive hover states.
- **Responsive Navigation:** Smart navbar that hides on scroll down and reveals on scroll up.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop devices.
